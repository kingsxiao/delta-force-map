# 三角洲行动 · 高清地图与打法详解

单文件静态网页：烽火地带六张地图（零号大坝 / 长弓溪谷 / 巴克什 / 航天基地 / 潮汐监狱 / AZ3核电站）的高清标注大图 + 实战打法 + 物资爆率参考。另有独立的**枪械 TTK 击杀时间排行**页（`ttk.html`，步枪 × 冲锋枪 × 各级弹药与护甲）。

## 使用

双击 `index.html` 用浏览器打开即可。完全离线、无任何外部依赖（图片全部内嵌）。

## 功能

- **页内交互地图查看器**：拖拽平移、滚轮以光标为中心缩放（1–7x）、双击放大、+/−/复位按钮、触屏单指拖动与双指捏合、键盘操作
- **169 个可点击标注**：出生点 / 撤离点 / Boss / 高价值物资点，四类分层可开关，点击弹出要点信息卡
- **逐出生点打法卡**：每个出生点四块——打法思路 / 需要注意 / 能抽过点的位置 / 哪里要封烟
- 撤离点条件、资源搜刮路线、Boss 情报、实战建议
- 每图物资点爆率表（社区统计口径）

## TTK 排行页（ttk.html）

- **36 把武器 × 13 种口径 × 全部弹药**的 TTK / BTK 排行，可切目标部位（胸 / 腹 / 头）与护甲等级（无甲 ~ 6 级），每枪可展开全部弹药的逐发模拟对比
- **穿透 × 护甲判定矩阵**（0% / 50% / 75% / 100% 国服社区实测口径）与弹药库全表
- 计算口径：100 血单血池、部位倍率、碎甲 k 值规则、TTK = (BTK−1)×60000/RPM，全部假设与来源在页内注明

## 数据说明

- 点位坐标来自官方地图工具公开数据；打法与爆率整理自社区公开资料（官方工具、wiki、图文与视频攻略），**未在游戏内逐条实测**
- 爆率为社区统计口径（S/A/B 分级 + 定性排名），官方从未公布精确百分比，可能与实际掉落有出入
- 数据基线 2026-08 ~ 2026-10，版本更新后以游戏内战术地图为准

## 目录

- `index.html` — 站点本体（单文件，含全部数据与图片）
- `ttk.html` — 枪械 TTK 击杀时间排行（单文件，步枪/冲锋枪 × 弹药 × 护甲逐发模拟）
- `shaders.iife.js` — 首页 WebGPU 特效库（雾 + 粒子 + 胶片颗粒；不支持时自动降级，可整块移除）
- `verify-effects.mjs` — 特效层自动化验证脚本（`node verify-effects.mjs`，零 npm 依赖）
- `assets/<地图>/hotspots.json` — 各图点位标定数据留档
- `assets/` 其余 — 各图原始高清底图留档
